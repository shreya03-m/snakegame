# 🐍 Snake Game

A classic Snake Game built using **HTML, CSS, and JavaScript** (or whatever stack you used — update accordingly).  
The goal of the game is to control the snake, eat food, and grow without colliding with the walls or yourself.  

---

## 🎮 How to Play
- Use the **Arrow Keys** (⬆️ ⬇️ ⬅️ ➡️) to move the snake.
- Eat the food 🍎 to grow longer.
- Don’t hit the wall or your own tail ❌.
- The game ends when you collide.

---

## 🚀 Features
- Smooth snake movement
- Score tracking
- Simple and fun design
